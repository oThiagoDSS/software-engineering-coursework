# 📐 Module 02: UML Systems Modeling

This module covers Object-Oriented Analysis and Design (OOAD) using Unified Modeling Language (UML) standard diagrams, including Class Diagrams, Sequence Diagrams, and State Machine Diagrams.

## 📂 Included Artifacts

1. **[Academic Control System (SiCAd)](./academic-control-system-sicad.md):** Domain modeling, class diagram specifications, and use cases for university administrative software.
2. **[UML Domain Case Studies](./domain-case-studies-uml.md):** Sequence and state diagrams for industrial case studies including Digital Banking and E-Commerce logistics.
