# 🏛️ Module 03: Architecture and Design

This module covers system architecture patterns, microservices design, component interaction models, and real-world system design for enterprise and real-time applications.

## 📂 Included Artifacts

1. **[Medical Appointment System](./medical-appointment-system.md):** Microservices architecture, API gateway routing, asynchronous notifications, and EHR integration.
2. **[University Library System](./university-library-system.md):** Layered N-Tier architecture, strategy pattern for penalty calculations, and observer notifications.
3. **[IT Service Desk](./it-service-desk.md):** Event-driven incident management, state machine workflow, and automated escalation pipelines.
4. **[Delivery App (Sabor Express)](./delivery-app-sabor-express.md):** High-concurrency event-driven architecture, WebSocket geospatial tracking, and CQRS patterns.
